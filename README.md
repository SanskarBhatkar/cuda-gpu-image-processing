CUDA GPU Image Processing

Project Description

This project implements GPU-accelerated image processing using CUDA C++. It applies a 3×3 box blur filter to grayscale images in PGM format.

Technologies Used

* CUDA C++
* NVIDIA CUDA Toolkit
* GPU parallel processing

Features

* Processes grayscale images.
* Applies a 3×3 box blur filter.
* Uses CUDA threads to process pixels in parallel.

Execution

The program requires a compatible NVIDIA GPU and CUDA Toolkit to compile and run.

Note

Actual GPU execution must be verified separately.
